The project

Jarvis — Greyson's private personal AI, his tool, explicitly not a tutor (his correction, Nov 23), that looks and acts like Iron Man's J.A.R.V.I.S.: a holographic HUD in the browser, backed by a Python server (server.py) and your jarvis.py core, talking to a local Ollama model (llama3.1). It answers his questions directly and completely and helps with whatever he is working on; explaining and quizzing are modes he can request, not the default. It does not write work for him to submit as his own.

Shared code lives in the private GitHub repo GreysonMarker/jarvis-assistant. The rulebook is AGENTS.md in that repo. Public pages: the HUD at greysonmarker.github.io and mission control at greysonmarker.github.io/hq/.

What Ultron changed in v2 — flagged for your review

Some of these touch jarvis.py, your lane. They were made at Greyson's explicit request, are covered by tests, and are in the PR for you to review — push back in the PR if you disagree.

  • Environment awareness: new env_context() in jarvis.py injects the live local date, weekday and time into every model turn as reference data (never saved to history). Fixes Jarvis saying "Good morning" at 10:13 PM.
  • JARVIS_FAST mode (env flag; the server defaults it on, JARVIS_FAST=0 restores your original behaviour): your per-message pipeline cost 3–6+ model calls — a search-decision call, a routing call, then one per specialist. In fast mode the search-decision call is skipped (search still runs for an explicit look up ...), specialists are chosen by local keyword match (fast_roles(), max 2, no routing call), so a normal message costs one model call. Motivation: the search-decision call once turned the question "29x37" into Wikipedia results about the Porsche 911 (991).
  • Instant arithmetic: in fast mode, pure calculations (29x37, "what is 29 x 37?") are evaluated locally by a strict AST walker (arithmetic()) with zero model calls.
  • generate() now sends keep_alive (env JARVIS_KEEP_ALIVE, default 30m) so the model stays loaded.
  • Deliberation mode (v3, Nov 23 — also flagged for your review): open-ended questions with no single right answer are detected locally by deliberation() (keyword patterns, no model call) and answered with a reasoning scaffold inside the single fast-mode answer call: a principles framework for normative questions ("Should a doctor ever withhold information...?"), a decision framework for personal choices ("Should I...?", "pros and cons of..."), bottom-line-first structure, a 220-word cap, and a token cap (generate() gained an optional options parameter; deliberation passes num_predict: 384) to hold the ~10s budget. Specialist consults are skipped on deliberation turns.
  • Smart lookup, adaptive depth, voice out (v4, Nov 23 evening — jarvis.py changes flagged for your review): needs_search() decides locally (no model call) when a question needs a web search — named events, possessive proper names ("Rykard's role in the Night of Black Knives"), quoted titles, casting questions, recency — so niche/lore questions search automatically while common knowledge and deliberation stay local; results cached on disk 24 h. depth_mode(), a /deep prefix and a HUD Deep toggle give long-form answers a 1,024-token budget (normal answers now capped at 800; deliberation 384, or 1,024 deep). Hedged answers trigger one rescue search, and successful searches are distilled into the knowledge/ folder. The prompt was restructured for Ollama's KV cache: stable system prompt, append-only history, all volatile context in the final user message; num_ctx pinned at 8192. The HUD gains a Voice toggle: answers spoken via browser speech synthesis (local British male preferred), the core held in its speaking state while he talks.
  • Long-chat memory + plain-words controls (v5, Nov 23 late — jarvis.py changes flagged for your review): history compression replaces the old silent 20-message cutoff — older turns fold into a compressed-memory note (start preserved, no model call), newest 16 verbatim; 200-question chats are tested. Slash-command dumps are gone: unknown /... input is treated as plain words, the no-model reply is a friendly sentence, and /help speaks plain words. New natural_command(): "remember that...", "what do you remember?", "forget...", "add a task:...", "task 2 is done" (position mapped to row id), "give me my briefing", "new chat". Old slash commands still work; nothing surfaces them.
  • Hard memory, clock reminders, topic sources, Piper (v6, Nov 23 late — jarvis.py/server.py changes flagged for your review): dictated facts are now hard memory — a pinned ground-truth block in every turn, outside trimming and chat compression ("never forget..." also lands there; chat memory remains the v5 rolling summary). Clock reminders ("remind me at 3pm to...") persist in reminders.json, announce on the next reply, and fire a macOS notification from a server thread. Search routes by topic: Elden Ring questions hit eldenring.wiki.gg first (_TOPIC_WIKIS). Optional Piper TTS: GET /api/tts/status + POST /api/tts; the HUD uses it when installed and falls back to the browser voice.
  • Multi-source search (v7, Nov 23 late — jarvis.py change flagged for your review): search_public now queries in parallel — the routed topic wiki, DuckDuckGo web, Reddit's own search, Wikipedia, and Brave when keyed — merging round-robin, deduped by URL, capped at 8 hits, each tagged with its source (source_label) in the prompt and the answer's results list; the model is told to cross-check and flag disagreements. Sources are best-effort (Reddit/DDG block datacenter IPs; on a normal connection they generally respond).
  • Candor (Nov 23 late, Greyson's standing instruction): Jarvis is a private single-user free-speech tool — VOICE now says so explicitly: engage any topic directly, never refuse for offensiveness, no moralizing or unrequested warnings, real opinions when asked. Also fixed a stale VOICE line (records no longer change "only via slash commands" since v5). Update: the posture is now a per-chat switch — the candor block lives in an UNRESTRICTED addendum; "unrestricted mode" appends it for that chat, "normal mode" or a new chat removes it. Base VOICE is the everyday default again.
  • Morning briefing (built Nov 23 evening, NOT yet shipped — flagged for your review, awaiting Greyson's pick): Greyson asked for Jarvis improvements beyond tutoring; the top-ranked idea from the research board is a /briefing command. New file briefing.py (stdlib only, no key): Houston weather from Open-Meteo, one "on this day" event from Wikipedia, ISS position from WhereTheISS.at, next launch from Launch Library 2, moon phase computed locally, plus open tasks and saved memories. No model call. Each source cached (launch 1h, weather 30 min) and fails independently. jarvis.py change is small: /briefing added to HELP and to command(). It is built and tested (54/54 tests pass including the new test_briefing.py and test_instant_tools.py) but is not in the v3 zip Greyson already has — it ships only if he picks it, on top of v3, after he installs v3.
  • Instant tools (built Nov 23 evening, NOT yet shipped — flagged for your review, awaiting Greyson's pick): the #2 idea from the same research board. New file instant_tools.py (stdlib only, no key): timer, open an app, screenshot, volume, speak aloud (say), battery — all via macOS built-ins, zero model calls, instant. Plain wording ("set a timer for 10 minutes", "take a screenshot") and slash commands (/timer 10m, /open Safari, /screenshot, /volume 50, /say hello). jarvis.py change: the new commands in HELP and command(), plus a local dispatch in reply() before the model call. Natural "open X" only fires for a short allowlist of common apps. A timer lives inside the running Jarvis process. Like the briefing, it is built and tested but not in the v3 zip — it ships with the briefing, on top of v3, if he picks it.
  • Server/HUD (Ultron's lane, no review needed): chats now persist per user as JSON, GET /api/chats lists them, GET /api/chats/<id> returns history, DELETE removes; the HUD has a Chats panel to swap between chats like ChatGPT, and reopens the most recent chat on load.
